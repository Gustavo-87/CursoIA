# Proyecto de Inteligencia Artificial - Resuelve

## 1. Problemática

La gestión de Peticiones, Quejas, Reclamos y Sugerencias (PQRS) en copropiedades puede generar un volumen considerable de información que debe ser revisada, clasificada y atendida por la administración.

El análisis manual de estas solicitudes puede dificultar la identificación de patrones, tiempos de atención, tipos de solicitudes recurrentes y casos que requieren mayor prioridad.

El proyecto propone utilizar técnicas de análisis de datos e Inteligencia Artificial para apoyar el procesamiento de la información generada por las PQRS y facilitar la toma de decisiones dentro de la plataforma Resuelve.

## 2. Datos

El proyecto utilizará información relacionada con las PQRS registradas en la plataforma. Inicialmente se podrán considerar datos como:

- Número de radicado.
- Tipo de PQRS.
- Estado de la solicitud.
- Fecha de radicación.
- Fecha de respuesta o cierre.
- Tiempo de atención.
- Contenido o descripción de la solicitud.

Para las primeras prácticas se utilizarán datos simulados almacenados en archivos CSV, permitiendo realizar ejercicios de lectura, procesamiento y análisis sin utilizar información real de los usuarios.

## 3. Objetivo

Desarrollar una solución basada en análisis de datos e Inteligencia Artificial que permita procesar información de las PQRS registradas en Resuelve, con el propósito de identificar patrones y generar información útil que apoye la gestión de las solicitudes.

Inicialmente, el proyecto se enfocará en el análisis de datos estructurados mediante Python. A medida que avance la asignatura, se evaluará la incorporación de técnicas de Inteligencia Artificial de acuerdo con los conocimientos adquiridos y los requerimientos definidos durante el curso.

## 4. Tecnologías

Para el desarrollo del proyecto se utilizarán inicialmente las siguientes tecnologías:

- Python.
- Docker.
- Docker Compose.
- Pandas para procesamiento y análisis de datos.
- CSV como formato inicial para almacenamiento de datos de prueba.
- Git para control de versiones.
- GitHub para almacenamiento y seguimiento del repositorio.
- Visual Studio Code como entorno de desarrollo.

Las tecnologías y librerías relacionadas específicamente con Inteligencia Artificial se incorporarán progresivamente de acuerdo con los temas desarrollados durante la asignatura.

## 5. Entregables

Durante el desarrollo del proyecto se generarán los siguientes entregables:

- Scripts en Python para lectura y procesamiento de datos.
- Archivos CSV con datos simulados para las prácticas.
- Ejercicios de análisis de PQRS.
- Funciones para cálculo de estadísticas básicas.
- Documentación técnica y académica del proyecto.
- Evidencias de ejecución de los ejercicios desarrollados.
- Repositorio actualizado en GitHub con el historial de cambios.
- Incorporación progresiva de técnicas de Inteligencia Artificial de acuerdo con el avance de la asignatura.
