# PROYECTOS ELEGIDOS:

## 1.Clasificación automática de preguntas

Este proyecto busca identificar automáticamente el tipo o categoría de una pregunta escrita por un estudiante, por ejemplo: matemáticas, programación, historia o soporte académico. Para desarrollarlo se necesitarían preguntas previamente clasificadas por categoría. 
Se podría utilizar **Naive Bayes**, un modelo de aprendizaje automático que clasifica información utilizando probabilidades. En este caso, aprendería qué palabras aparecen con mayor frecuencia en cada categoría y, al recibir una nueva pregunta, calcularía a cuál categoría es más probable que pertenezca. Es un modelo sencillo, rápido y utilizado comúnmente para clasificación de textos.

## 2. Clasificador de PQRS

Este proyecto busca clasificar automáticamente las peticiones, quejas, reclamos y sugerencias (PQRS) que presentan los ciudadanos, facilitando su organización y posterior atención. Para desarrollarlo se necesitaría un conjunto de PQRS previamente clasificadas según su tipo.

Se podría utilizar un modelo de **Naive Bayes**, ya que permite clasificar textos a partir de las palabras que contienen y la probabilidad de que pertenezcan a determinada categoría. Por ejemplo, expresiones relacionadas con una inconformidad podrían ayudar al modelo a identificar un reclamo o una queja.

## 3. Priorización de solicitudes

Este proyecto busca analizar las solicitudes recibidas y determinar cuáles deberían atenderse primero según su nivel de prioridad. Para desarrollarlo se necesitarían solicitudes anteriores con información como su descripción, tipo y nivel de prioridad asignado.

Se podría utilizar un modelo de **Árbol de Decisión**, que aprende reglas a partir de los datos para clasificar cada solicitud, por ejemplo, como prioridad alta, media o baja. Este modelo permite entender fácilmente qué características fueron utilizadas para tomar la decisión.
